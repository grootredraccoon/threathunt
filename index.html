브라우저 캐시 저장 안내 STORAGE NOTICE
작성한 인시던트와 Stage 정보는 이 브라우저에 자동 저장됩니다.
다만 사이트 데이터나 브라우저 저장소를 삭제하면 내용이 사라질 수 있으니, 중요한 기록은 백업 파일로 따로 저장해 주세요.
  • 1
    브라우저 캐시 / 사이트 데이터 초기화시 모든 인시던트·Stage·이미지가 즉시 삭제됩니다. 설정 → 개인정보 → 인터넷 사용 기록 삭제 주의
  • 2
    시크릿(InPrivate) 모드에서는 브라우저를 닫는 순간 데이터가 사라집니다. 시크릿 모드 사용을 지양하세요.
  • 3
    다른 기기·다른 브라우저에서는 데이터가 공유되지 않습니다. 중요한 데이터는 반드시 JSON / MD / PDF 로 백업하세요.
✔ 권장 운용 방식 로컬 웹 서버에서 이 HTML 파일을 열면 훨씬 안정적입니다.
터미널에서 파일 경로로 이동 후 python3 -m http.server 8080 실행 → 브라우저에서 http://localhost:8080 접속.
데이터는 여전히 localStorage에 저장되지만, 캐시 정책의 영향을 덜 받습니다.
